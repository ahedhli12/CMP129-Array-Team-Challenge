# CMP 129 – Array Team Challenge

## Goal

Work with your team to analyze an array of student exam scores.

You will practice:

- Traversing arrays with loops
- Using `.length`
- Performing calculations with array values
- Finding the highest value
- Using conditions with arrays
- Working collaboratively in Visual Studio Code

## Teamwork

Work in teams of 2–3 students.

Suggested roles:

- **Student 1:** Calculate the average
- **Student 2:** Find the highest score
- **Student 3:** Count scores above the average

Use **Visual Studio Code Live Share** so all team members can participate.

Everyone should be prepared to explain the team's code.

---

# Starting Data

Your program will use:

```java
int[] scores = {78, 92, 85, 67, 95, 88, 73, 90};
```

## Challenge 1 – Display the Scores

Use a loop to display every score.

Do not write a separate `println()` statement for every value.

---

## Challenge 2 – Calculate the Average

Calculate and display the average of all scores.

Expected format:

```text
Average Score: 83.5
```

Do not manually add the scores.

Your solution must continue to work if more scores are added to the array.

---

## Challenge 3 – Find the Highest Score

Use a loop to determine the highest score in the array.

Expected format:

```text
Highest Score: 95
```

Do not simply print `95`.

Your program must determine the highest value from the array.

---

## Challenge 4 – Scores Above Average

Determine how many scores are above the calculated average.

Expected format:

```text
Students Above Average: 4
```

Your answer must be calculated by the program.

---

## Bonus Challenge

If your team finishes early, display the scores in **reverse order**.

Example:

```text
90
73
88
95
67
85
92
78
```
